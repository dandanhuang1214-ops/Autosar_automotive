# AI 平台驻留、图谱回答与云端 API 评估（2026-11-07）

范围：现有 Ollama `0.31.1` / RTX 3050 Ti Laptop 4 GB；图谱为站点 v5 的已核对本地快照。原始模型 trace 仅在本机忽略目录保存。本轮不调用云端 API，不发送私有图谱或工程报告到外部服务。

## 本地改动与试验

- 普通聊天完整/流式路径增加服务端 `--chat-keep-alive {2m,5m,10m}`，默认仍为 `2m`；实验用 `5m`。它控制模型驻留时间，不改变上下文或生成上限。
- 图谱候选从最多 3 节点/6 片段收为最多 2 节点/4 片段；提示要求仅回答问题本身、逐事实对应直接相关片段。旧三题和新开发三题的目标片段均位于前两节点；仍需在更多不同问题上查召回。旧三题实际来源提示约 600–900 字，故缩短提示本身并非主要提速手段。
- [新开发三题](ai-chat-graph-quality-cohort-20261107.json)在推理前固定，使用 `qwen3.5:2b`/5m：3/3 有目标片段且引用编号有效；热态首字 0.99–1.15 秒、生成 68.9–70.1 token/秒；首题冷态首字 23.48 秒。回答仍出现 DID 限制与 F111 布局的题外串联或无依据配置建议，内容门失败。原始包 `output/ai-chat-keepalive-5m-20261107/`。
- 收紧后再固定[三道未见题](ai-chat-graph-quality-heldout-20261107.json)：3/3 召回目标，热态首字 1.05–1.44 秒、生成 67.6–70.9 token/秒；一题只写 `[1]` 而非 `[资料1]`，引用审阅器判 `missing`；另有回答增添题外细节，不能据此宣称语义质量通过。原始包 `output/ai-chat-heldout-5m-20261107/`。Codex 本次审阅非独立人工验收。
- 2B 最小 `keep_alive=5m` 探针冷加载 44.55 秒；探针后 `ollama ps` 显示 8192 context、100% GPU，`nvidia-smi` 显示 3194/4096 MiB。驻留会占用约 3.2 GB 显存；连续对话的热态收益不等于生成速度提高。未完成同一条件下等待超过 2 分钟再请求的严格 A/B，因此不宣称 5m 已量化减少多少次冷加载。

## 隔离 4B 加速探针

临时容器复用本机已有 `ollama/ollama:latest` 镜像，以只读方式挂载原模型卷，独立端口 11435；设置 `OLLAMA_FLASH_ATTENTION=1` 和 `OLLAMA_KV_CACHE_TYPE=q8_0`，原容器全局设置未变。用已保存的同一 First Frame 提示、`qwen3.5:4b`、8192 context 完成一次请求。日志确认 `--flash-attn on`、K/V `q8_0`，但仍只卸载 23/33 层到 GPU，CPU 映射模型 1135 MiB；调用冷加载 80.15 秒、提示处理 39.23 秒、输出 101 token 用 11.46 秒（8.81 token/秒）。一次冷态请求与前轮热态 15.8 token/秒不构成严格速度 A/B；能够确定的是**没有全 GPU 驻留，也没有观察到足以更换默认模型的速度优势**。临时容器已关闭并自动删除，原模型文件保留。

## 云端 API 选择

建议把云端作为**可选的工程问答质量基线**，保留本地 `qwen3.5:2b` 用于普通快速聊天。用相同冻结题比较首字、全答、每题费用、目标召回、引用编号和逐句事实支持；是否更快取决于网络与服务端负载，不能从本地 4B 慢直接推定云端时延。图谱检索与证据校验仍在本地，只有经授权选择的最小相关片段进入云端请求；模型回答继续显示为草稿而非工程判定。密钥仅放服务端环境/密钥库，并设额度、超时和失败回退。

以 OpenAI 官方文档为一个**示例**：当前标准短上下文价格表按每百万输入/输出 token 计价，[价格页](https://developers.openai.com/api/docs/pricing)列有不同速度/模型档。按表中 `gpt-6-luna` 0.10/0.50 美元与 `gpt-6.1-sol` 2/10 美元，假设单次 1000 输入 + 200 输出 token、无缓存/工具/额外处理费，分别约 0.0002 与 0.004 美元；实际费用取决于模型、服务档、token 与附加工具，接入前应重查官方价格。官方[数据控制说明](https://developers.openai.com/api/docs/guides/your-data)称 API 输入输出默认不用于训练（除非主动选择共享），但滥用监测日志默认可能含客户内容并保留最多 30 天；零保留需满足资格并获批准。因此私有站点原文、未公开项目报告、客户资料须按来源许可与保密要求单独决定是否允许发送，不能因“API 默认不训练”就当作本地处理。

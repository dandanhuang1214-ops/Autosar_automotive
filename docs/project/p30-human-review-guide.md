## 执行顺序

1. 先复验项目和模型归档，记录实现 SHA、提示版本、模型 digest、冻结清单摘要及逐题归档摘要。复验失败的样本标记 invalid，不修补后混入原试验。
2. 审阅者先看问题与项目事实，独立记录应回答的对象、状态、类型化值、证据不足时应拒答的范围，再看模型回答。代理已有 gold 仅作对照，不冒充独立人工标注。
3. 项目事实与手册分别审核。手册须记录文档版本、页码/片段、适用平台及是否直接支持当前解释；“逐字引用正确”不能替代相关性和适用性。
4. 对通过结构化校验的回答逐项核对下表；没有合格回答时保留 not-assessable，不把服务失败记为模型正确拒答或语义错误。
5. 保存原始意见、修改前后结论及分歧。看过的题目只能用于开发或回归；后续验收另冻结新问题并明确其与已有样本的关系。

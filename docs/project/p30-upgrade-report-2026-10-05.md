## 已有资料和仍缺的东西

现场清单有 **23 份文档**：15 份启用/ready/approved；4 份 AI 草稿 pending；1 份解析 failed；3 份 disabled。可用文档目前保留 `legacy_trusted` 来源等级，没有被工作台擅自改成 official。草稿、未审核和失败资料不进入本轮解释来源。

现有资料主要覆盖 Simulink、Stateflow、SWC/Runnable/RTE 建模。目录中未看到独立 COM/PduR/CanIf/CanTp/Dcm 规范条目；这不等于全文中完全没有相关内容，仍需按具体工程问题核查版本和适用性。

当前缺口：

1. 小模型的稳定结构化输出、复杂引用与拒答能力尚未通过独立评测。
2. 手册摘录存在不等于适用于本项目；资料版本、问题相关性仍需评测。
3. 六类工程问题（配置拒绝、影响范围、CAN 超时、诊断负响应、缺证据、历史替换）的独立模型评测尚未完成。
4. 自然语言语义、建议可用性与人工使用反馈尚未验收。
5. 新工程解释入口目前是 CLI/归档，尚未接入原 Web 界面。

缺口输出区分项目未满足的门、当前上下文未选取的事实、资料未请求/查询失败/无命中，以及模型/语义验收缺口。一次查询无命中不会被描述成整个知识库缺失该类资料。

原服务停止时的真实 blocked 回退也已保存。提示版本 0.1–0.4 保留重放支持，失败输出未被补号、改写或替换。

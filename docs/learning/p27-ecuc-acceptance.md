# P27 独立练习：配置变更验收

平台实现证据不代表个人已掌握。请独立完成并保存命令、解释和输出：

1. 安装 wheel，运行两个公开项目；解释为什么精简工程 passed 而应用检查 unassessed。
2. 复制候选配置，清空任务引用；定位失败要求、原 XML 位置与影响依赖见证。说明为何这不是厂商有效性或可调度性证明。
3. 移除应用 ARXML 声明，解释与任务引用缺失的区别；再加入未知厂商字段，验证不可获得完整影响结论。
4. 比较同一基线/策略的正常和失败运行；修改基线或要求文本，解释 not-comparable。
5. 删除原输入并搬移整个交付树，复验项目与比较；篡改一份来源确认拒绝。

使用 [操作指南](../project/p27-ecuc-acceptance-guide.md)。每项分别记录未开始/需提示/独立完成；不要直接把自动 CI 计作独立完成。

# P28 独立练习：配置有效与变更获准

先阅读[操作指南](../project/p28-object-policy-guide.md)。以下要求本人独立执行并解释；代理测试通过不代表已掌握。

1. 将完整工程基线、候选分开复制，保持相同策略，把 ComBitSize 从 8 改为 12。定位 SIGNAL_SIZE 失败的两侧值和 XML 源位置。
2. 把任务引用从 TaskA 改到存在的 TaskB。解释为什么 task_bindings 通过而 TASK_REF 失败，以及这两项各自能证明什么。
3. 预先选择只保护信号结构的策略，运行相同位宽变更。说明为什么允许它不等于证明布局或物理总线正确。
4. 改变保护对象后比较两份项目报告。解释 not-comparable 与 regressed 的区别，不以削弱策略获得“回归通过”。
5. 删除原输入并搬移输出树，独立运行 verify-ecuc-project；再修改一个 observation 值，确认复验拒绝。说明来源哈希与独立来源认证的区别。

保存命令、返回码、报告路径和自己的解释。人工完成情况仍需另行记录。
